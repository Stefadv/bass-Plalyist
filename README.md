MISE A JOUR DE INDEX.HTML SUR GITHUB

1. Télécharger le nouveau fichier HTML généré.

2. Renommer le fichier en :
   index.html

3. Ouvrir le dépôt GitHub contenant le site.

4. Remplacer l'ancien fichier index.html :
   - soit en supprimant l'ancien puis en téléversant le nouveau,
   - soit en écrasant directement le fichier existant.

5. Cliquer sur :
   Add file > Upload files

6. Sélectionner le nouveau fichier index.html.

7. En bas de la page :
   Commit changes

8. Choisir :
   Commit directly to main

9. Valider le commit.

10. Attendre 30 secondes à 2 minutes que GitHub Pages se mette à jour.

11. Ouvrir le site et forcer le rechargement :
   Windows : Ctrl + F5
   Mac : Cmd + Shift + R

Méthode GitHub Desktop

1. Remplacer index.html dans le dossier local du projet.
2. Ouvrir GitHub Desktop.
3. Vérifier que index.html apparaît dans les modifications.
4. Saisir un message de commit :
   Update index.html
5. Cliquer sur Commit to main.
6. Cliquer sur Push origin.
7. Attendre la publication du site puis actualiser la page.
